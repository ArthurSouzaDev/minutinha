# 0005. Licença MIT

- **Status:** Aceito
- **Data:** 2026-11-18

## Contexto

O projeto é open source e deve ser fácil de usar, estudar e contribuir.

## Decisão

Licenciar o código sob **MIT**.

## Alternativas consideradas

| Opção | Prós | Contras
|---|---|---|
| **MIT** | Simples, permissiva, compatível com PySide6 (LGPL), faster-whisper (MIT) e Whisper (MIT) | Permite uso fechado por terceiros |
| GPL-3.0 | Garante derivados abertos | Afasta parte dos contribuidores/usos |
| Apache-2.0 | Cláusula de patentes | Mais verbosa |

## Consequências

- Conferir e documentar a licença de cada modelo LLM sugerido e do build do ffmpeg embutido (LGPL/GPL conforme build).
